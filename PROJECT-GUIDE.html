1. Use Case

Chicago Elite Limo is a limo/car service booking website (inspired by eminentlimo.com, royalcarriagelimo.com, and americancoachlimousine.com). Customers fill out a ride booking form (pickup/drop-off, date, time, vehicle type, passengers, etc.) and submit it directly from the site — no phone call required.

On submission, the request is automatically delivered via WhatsApp to:

  • The business owner — an alert with the full booking details.
  • The customer — a confirmation of their ride request (with their consent).

This removes the need for a customer-facing backend dashboard while still giving the business owner instant, real-time notification of every booking request.

3. Features

Built & verified DONE

  • Full multi-page UI: Home, Booking, Fleet, Services, About, Contact (black & gold luxury theme, responsive)
  • Thymeleaf templates wired to Spring Boot controllers (PageController)
  • POST /api/bookings endpoint with request validation (BookingRequest DTO, ApiExceptionHandler)
  • WhatsAppService — Twilio SDK integration, sends to owner + customer via Content Templates
  • Graceful degradation — app runs fine and logs a warning if Twilio credentials aren't configured, instead of crashing
  • Consent checkbox on the booking form (required before messaging the customer, per Meta policy)

Built, but blocked by local network BLOCKED (env only)

  • Live WhatsApp delivery — confirmed working via a direct curl test outside this workspace's network. Inside this dev environment, a corporate proxy (Zscaler) intercepts/resets the JVM's outbound TLS connection to Twilio's API. Not a code issue — needs testing from an unrestricted network or a deployed environment.

Designed, not yet implemented PLANNED

  • Distance/pricing calculation via a routing API (Mapbox or Google Maps)
  • Live address autocomplete on pickup/drop-off fields
  • Database persistence for bookings and users (PostgreSQL + Spring Data JPA)
  • Guest booking with a random booking reference + phone-verified /track page (view status, cancel — no login required)
  • Optional customer accounts (booking history, faster rebooking)
  • Admin login with role-based access (Spring Security) to view/manage all bookings
  • AWS deployment (RDS + EC2/Lightsail)

5. Running the Application

Prerequisites

  • Java 17 (JAVA_HOME must point to a JDK 17 installation)
  • Maven 3.9+
  • A Twilio account with WhatsApp Sandbox or an approved WhatsApp Sender, plus at least one Content Template

Build

mvn clean compile

Run (with WhatsApp sending disabled — safe default)

mvn spring-boot:run

The app starts on http://localhost:8080. Without Twilio env vars set, booking submissions are still accepted and return success, but WhatsApp sending is skipped with a logged warning.

Run (with WhatsApp sending enabled)

Set the environment variables listed in the next section first, then run the same command:

mvn spring-boot:run
Never hardcode Twilio credentials in application.yml or any committed file. Always supply them as environment variables (or a local, git-ignored application-local.yml).

6. Environment Variables

VariableRequiredExampleDescription
TWILIO_ACCOUNT_SID Yes (to enable WhatsApp) ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx Your Twilio Account SID
TWILIO_AUTH_TOKEN Yes (to enable WhatsApp) <your auth token> Your Twilio Auth Token — treat as a secret, rotate immediately if ever exposed
TWILIO_WHATSAPP_FROM No (defaults to sandbox) whatsapp:+14155238886 Your Twilio sandbox number or approved WhatsApp Sender, in whatsapp:+E164 format
OWNER_WHATSAPP_NUMBER Yes (to notify the owner) whatsapp:+13125550100 The business owner's WhatsApp number that receives booking alerts
TWILIO_CONTENT_SID_OWNER Yes (to notify the owner) HXxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx Approved/sandbox Content Template SID used for the owner alert message
TWILIO_CONTENT_SID_CUSTOMER Yes (to notify the customer) HXxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx Approved/sandbox Content Template SID used for the customer confirmation message

Example (PowerShell, current session only)

$env:TWILIO_ACCOUNT_SID="AC..."
$env:TWILIO_AUTH_TOKEN="your_token"
$env:TWILIO_WHATSAPP_FROM="whatsapp:+14155238886"
$env:OWNER_WHATSAPP_NUMBER="whatsapp:+13125550100"
$env:TWILIO_CONTENT_SID_OWNER="HX..."
$env:TWILIO_CONTENT_SID_CUSTOMER="HX..."
mvn spring-boot:run

7. Known Issues

  • Corporate network blocks outbound Twilio calls in this dev environment. A Zscaler proxy intercepts TLS traffic on this machine, causing the JVM's HTTPS connection to Twilio's API to fail (PKIX / connection reset errors), even though the same Twilio credentials work correctly via a direct curl test outside this network. To verify live WhatsApp delivery, test from an unrestricted network or a deployed environment.
